# Ollama Cloud 실제 연결 검증 — 2026-11-16

## 범위와 결론

사용자가 로컬 숨김 입력으로 키를 설정한 뒤 실제 테스트와 저가 모델 선택을 승인했다. 키 값은 출력/문서화하지 않았다. 인증·실제 모델 요청·캐시 재사용·잘못된 근거 거절·실패 재처리까지 확인했다. **운영 품질·수익성 검증 완료는 아니다.** 실제 메신저/주문/예약 실행은 하지 않았다.

## 모델과 비용

- `/api/tags` 인증 HTTP200, 계정의 모델 목록 확인.
- 긴 영상 자막이 대부분인 입력에 대해 `nemotron-3-super` 선택. DeepSeek가 항상 최저가는 아니다.
- 공개 요금(100만 토큰): 입력$0.015, 출력$0.60. 비교 모델 gpt-oss:20b는 입력$0.07/출력$0.30이므로 출력/입력 비율에 따라 순위가 달라진다. 이번 응답 사용량은 입력 중심으로 Nemotron이 저렴한 경우다.
- `/api/show`에서 thinking의 false/true 지원을 확인하고 `think:false`로 요청. 응답 받은 추론들에서 thinking 텍스트가 없음을 확인.
- 최초3회, 프롬프트 보완 후3회, 실패 영상만1회 재처리: **추론 요청 총7회**. 자동 재시도는 없다.
- HTTP200 응답6회, 네트워크 오류1회. 보고된 입력20,379토큰/출력492토큰.
- 응답 받은 요청의 공개 요금 기준 추정 **$0.000600885**. 응답 없는1건은 토큰/과금 여부 미확인이므로 이 값을 전체 실제 청구액으로 단정하지 않는다. 구독 크레딧·요금·과금 내역은 계정에서 확인해야 한다.

공식 참조: [가격표](https://ollama.com/pricing), [Chat API](https://docs.ollama.com/api/chat), [Thinking](https://docs.ollama.com/capabilities/thinking).

## 실험 자료

기존 `data/three-source-check.sqlite3`의 수집 관찰을 `data/ollama-live-test.sqlite3`로 백업해 원본을 보존했다. 대상은 엠비디의 사이트/영상/블로그 관찰3건이었다. 실시간 재수집·오늘자 투자 판단이 아니라 이미 수집한 자료에 대한 연결 검증이다.

처음에는2건에서 모델이 인용을 바꾸어 원문 검증에 실패했고, 사이트 ❌를 개인의 미참여로 해석하는 오류도 발견했다. 검증을 느슨하게 하지 않고 다음을 보완했다.

1. 원문에서 짧은 인용 후보를 제공해 그대로 선택하게 했다.
2. 모델 입력에서 중복 자막 segments를 빼고 원문 텍스트는 유지했다. 원래 시간 구간은 로컬 provenance에 남는다.
3. 사이트 평가는 평가로, 개인의 참여 의사는 별도로 해석하도록 예시를 보강했다.
4. 실제 요청/토큰 메타데이터를 `ollama_usage`에 보관한다. 키·HTTP 헤더·원응답/생각 과정은 저장하지 않는다.

보완 후 사이트와 블로그는 정상 검증됐으며 영상의 네트워크 오류는 한 번의 별도 재실행으로 응답을 받았다. 성공2건은 캐시를 재사용했다.

## 실제 자료에서 발견한 연결 오탐

영상 자동자막의 ‘엠비디아’라는 문자열이 ‘엠비디’ 종목의 단순 부분 일치 후보로 잡혔다. 모델도 이유에서는 종목 관련 진술이 없다고 하면서 평가를 negative로 주는 모순이 있었다. JSON·원문 인용 검증만으로 의미 정확성을 보장할 수 없다는 사례다.

`evidence.py`에 종목명/등록 별칭이 독립적인 이름 또는 일반 조사와 결합한 형태인지 확인하는 `match_quality`를 추가했다. 부분 문자열 후보는 삭제하지 않고 원문·관찰에 남기되 `substring_candidate`로 표시한다. 분석 계층은 이를 미확정 연결로 보류하고 점수를 확정하지 않는다. 짧은 이름/붙여쓴 글/자막 오타는 사람 확인·명시적 별칭 보강이 필요한 경우가 있다.

이 보완의 재검증에는 API를 호출하지 않았다. 기존 사이트/블로그 성공 캐시2건을 재사용하고 잘못 연결된 영상1건을 `analysis_target_ambiguous`로 보류했다.

| 출처 | 최종 처리 |
| --- | --- |
| 사이트 | ❌ 표시를 부정적 평가 신호로 보존. 개인 참여 의사는 판단 불가 |
| 팽 블로그 | 제목·설명에 있는 청약 패스 근거로 미참여 의사 추출 |
| 영상 | 다른 이름의 부분 일치 후보로 연결 확인 대기. 실제 엠비디 의견이라고 확정하지 않음 |

현재 실험 종합 결과는 **추가 확인**이다. 운영에 바로 사용할 수 있다는 결론이 아니다.

## 로컬 확인

```bash
uv run ipo-monitor credentials status ollama
uv run ipo-monitor decisions --db data/ollama-live-test.sqlite3 --stock 엠비디 --history
uv run ipo-monitor notification-preview --db data/ollama-live-test.sqlite3 --stock 엠비디
```

위 조회는 실제 API·메신저를 호출하지 않는다. 상세 실험 보고서는 `data/ollama-live-test-report.json`에 있으며 DB·키·실제 원문과 함께 Git 제외다.

최종 오프라인 회귀: 테스트208개, compileall, diff 검사. 향후에는 다른 종목과 명시적 참여/조건부 사례로 품질을 추가 측정하고, 명시적 별칭/이름 오인식을 다룬 뒤 실제 알림을 별도 연결한다. 이번 검증 이후 추가 실호출은 자동 실행하지 않았다.
